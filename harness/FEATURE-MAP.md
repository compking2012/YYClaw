## Decomposition Rules

- Preserve feature IDs and link PRODUCT/ARCHITECTURE sections from each new bounded task. Add featureIds metadata for new or substantially edited tasks; current CLI does not enforce this metadata.
- Treat uncovered mobile, persistent-host deployment, placement, migration, video and production-governance work as backlog. Create a scenario with ownership and acceptance before claiming coverage, and tasks only when an implementation slice is concrete.
- F26 remains tracked as a requirement. Existing Agent management/subagent tasks do not implement the removed local collaboration draft or full coordinated parallel execution.
- Cross-cutting constraints belong in specs/rules; durable technical detail belongs in reference. Neither replaces feature delivery evidence.
- For requirement revisions update this map; after accepted implementation update FEATURELIST and only the implemented portion of the multilingual introductions.
